# Design prototypes

Single-file, clickable HTML prototypes. Open them directly in a browser. All data is synthetic; every service is simulated.

| File | Surface |
|---|---|
| `clearpath-patient-app.html` | Patient phone app (OTP, home, medicines, to-do, help, chat, check-in, share, teach-back, expired) |
| `clearpath-provider-app.html` | Provider desktop app (login, dashboard, capture, transcript, review and approve, translate, publish) |
| `clearpath-coordinator-app.html` | Coordinator and admin app (escalations, audit and purge, time-travel) |

Use them as the visual and copy reference when building the Next.js app. Each has a "Prototype navigation" menu to jump to every state.
